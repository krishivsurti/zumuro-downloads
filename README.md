# Zumuro downloads

Official Android APK releases for [Zumuro](https://zumuro.web.app).

[Download Zumuro for Android v1.3.1](https://github.com/krishivsurti/zumuro-downloads/releases/download/android-v1.3.1/Zumuro-Android-1.3.1.apk)

Requires Android 8.0 or newer. Includes background playback and media controls in notifications and on the lock screen. Music streams online.

Download the APK on your Android phone and open it to install or update Zumuro. If prompted, allow installation from the browser you used to download it.

The release includes a SHA-256 checksum file for verification. This repository distributes signed APK releases; it does not contain the application source code.

Windows is coming soon. You can also use the [browser player](https://zumuro.web.app/app).
