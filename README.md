# Zumuro downloads

Official Android APK releases for [Zumuro](https://zumuro.web.app).

[Download Zumuro for Android v1.4.3](https://github.com/krishivsurti/zumuro-downloads/releases/download/android-v1.4.3/Zumuro-Android-1.4.3.apk)

Requires Android 8.0 or newer. Includes background playback, notification and lock-screen controls, and a rolling recommendation queue for songs started outside playlists. Songs you add manually play first. Music and recommendations require an internet connection.

Download the APK on your Android phone and open it to install or update Zumuro. If prompted, allow installation from the browser you used to download it. Existing Zumuro users can install this signed update over the current app.

Each release includes a SHA-256 checksum file. This repository distributes signed APK releases; it does not contain the application source code.

Windows is coming soon. You can also use the [browser player](https://zumuro.web.app/app).
